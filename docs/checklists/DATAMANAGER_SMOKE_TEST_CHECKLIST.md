# DataManager 스모크 테스트 체크리스트

## 목적
분리/캡슐화 이후에도 실제 플레이 흐름(로드, 저장, 전환, 장착, 레벨업)이 정상 동작하는지 빠르게 확인한다.

## 사전 조건
1. 테스트 씬: `GameScene`
2. 기존 저장 데이터가 있는 상태 1회, 없는 상태 1회 각각 수행
3. 콘솔 에러/예외 창을 켠 상태로 테스트

## 케이스 A: 첫 실행(저장 없음)
1. 앱 실행 후 게임 진입
2. 기본 플레이어 데이터가 생성되는지 확인
3. 기본 장착(슬롯1 기본 아이템)이 표시되는지 확인
4. 콘솔에 치명 에러가 없는지 확인

## 케이스 B: 일반 로드(저장 있음)
1. 앱 재실행 후 게임 진입
2. 마지막 플레이어 상태(스탯/DAYLV/장착)가 복원되는지 확인
3. 상점/장착 UI 진입 시 데이터 누락 없이 표시되는지 확인

## 케이스 C: 플레이어 전환
1. 캐릭터 1 -> 2 -> 3 순서로 전환
2. 각 캐릭터 장비 슬롯/스탯 UI가 즉시 갱신되는지 확인
3. 전환 후 다시 원래 캐릭터로 돌아왔을 때 이전 상태가 유지되는지 확인

## 케이스 D: 장착/해제/저장
1. 아이템 장착 후 슬롯 반영 확인
2. 아이템 해제 후 슬롯 반영 확인
3. 슬롯 저장 호출(`SavePlayerItem`) 후 앱 재실행
4. 재실행 후 슬롯 상태가 저장값과 일치하는지 확인

## 케이스 E: 레벨업 반영
1. 루틴/근육 관련 액션으로 EXP 증가 유도
2. 해당 근육의 Fill/UI가 정상 갱신되는지 확인
3. 플레이어 전환 후 복귀 시 값이 유지되는지 확인

## 케이스 F: 포맷/초기화 경로
1. `FormatAllPlayerData()` 실행
2. 전체 플레이어 데이터 초기화 확인
3. 장비 슬롯 초기화 및 기본값 재생성 확인

## 판정 기준
1. 콘솔 `Error/Exception` 0건
2. 저장/재실행 후 데이터 불일치 0건
3. 플레이어 전환/장착/레벨업 UI 갱신 누락 0건
